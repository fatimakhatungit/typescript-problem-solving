# TypeScript Problem Solving

## Overview

This repository contains my solutions for the **Problem Solving with TypeScript & OOP** assignment from Programming Hero Next Level (Batch 08).

The assignment focuses on practicing TypeScript fundamentals, problem-solving, and Object-Oriented Programming concepts.

## Topics Covered

- TypeScript basic types and function parameters
- Union types and type narrowing
- Readonly tuples
- Generics and `keyof`
- Interfaces and array methods
- Classes and inheritance
- Access modifiers
- Asynchronous programming with Promises
